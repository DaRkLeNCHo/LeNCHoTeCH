# LeNCHoTeCH

## Todo lo que pase es mi culpa

LeNCHoTeCH es una tienda virtual simulada desarrollada como proyecto académico utilizando HTML, CSS y JavaScript puro.

Su objetivo es demostrar el desarrollo de una página web moderna e interactiva para la gestión y visualización de productos tecnológicos relacionados con distintas categorías estudiadas en CompTIA A+.

---

# Objetivo

Desarrollar una demostración funcional de una tienda tecnológica que permita a los usuarios explorar un catálogo de productos mediante una interfaz intuitiva, incorporando funcionalidades comunes en sitios de comercio electrónico sin depender de bases de datos ni frameworks externos.

---

# Funcionalidades

- Catálogo dinámico de productos.
- Búsqueda en tiempo real.
- Filtros por categoría y subcategoría.
- Ordenamiento por distintos criterios.
- Carrito de compras.
- Sistema de favoritos.
- Comparación de hasta tres productos.
- Modo claro y oscuro.
- Diseño adaptable (Responsive Design).
- Manejo automático de imágenes faltantes.
- Persistencia mediante LocalStorage.

---

# Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage

No se utilizaron frameworks ni librerías externas para la lógica del proyecto.

# Características principales

El catálogo se genera completamente desde JavaScript.

Los productos pueden buscarse, filtrarse, ordenarse, añadirse al carrito, marcarse como favoritos y compararse sin necesidad de recargar la página.

La información del carrito, favoritos, tema y comparación permanece guardada mediante LocalStorage.

---

# Relación con CompTIA A+

Los productos incluidos en el catálogo fueron organizados tomando como referencia las categorías de hardware estudiadas en el dominio 3 del examen CompTIA A+, incluyendo:

- Displays
- Cables y conectores
- RAM
- Almacenamiento
- Componentes internos
- Fuentes de poder
- Impresoras
- Productos de mantenimiento

# Cómo ejecutar el proyecto

1. Descargar el proyecto.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar un servidor local (por ejemplo Live Server).
4. Abrir la página en el navegador.

No requiere instalación de dependencias.
